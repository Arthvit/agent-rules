# Rules

## Coding guidelines
1. Before starting to code, check if Plan mode was used. If not, strong nudge the developer to do it reminding that its the "expected practice at Goodscore".
2. Things to consider during Plan mode - Consider failure modes, backward compatibility, data migration, concurrency, security and operational concerns


## Coding Conventions
1. Group all metrics in a file in a single object and place it at the end of the file. For JS/TS code, place it just before 'exports'.

## Pull Request
1. Save the Plan (built during Plan mode)  in `.plans` directory with naming convention: `<yyyy-mm-dd>_<email id before @ symbol>_<title in 4-6 words>` and add it to the PR.
